너는 교육용 인터랙티브 웹앱을 설계하고 구현하는 시니어 프론트엔드 개발자이자 과학교육 UX 디자이너다.

나는 문과 대학생이라 공대·자연대에서 배우는 과학 이론을 접하면 수식과 전문용어 때문에 이해하기 어렵다.

이 문제를 해결하기 위해
"어려운 대학 과학 이론을 직접 조작하고 실험하면서 이해하는 인터랙티브 과학 학습 웹앱"
을 만들어라.

앱의 임시 이름은 "SCIENCE LAB"이다.

핵심 철학은 다음과 같다.

"읽어서 외우는 과학이 아니라, 직접 움직여서 이해하는 과학"

단순한 과학 백과사전이나 텍스트 중심 학습 사이트를 만들지 말고,
각 과학 이론마다 사용자가 직접 변수와 요소를 조작하고,
그 결과가 화면의 애니메이션·그래프·수치·현상으로 즉시 나타나는 체험형 학습 앱으로 만들어라.

==================================================
5. 40개 이론별 인터랙티브 실험
==================================================

각 실험은 반드시 실제 원리와 연결되어야 한다.
단순히 장식적인 애니메이션을 넣지 않는다.


--------------------
1. 뉴턴의 운동법칙
--------------------

화면에 물체가 있다.

사용자가:
- 질량
- 힘
- 마찰
- 초기속도

를 조절한다.

F = ma에 따라 가속도가 실시간으로 변한다.

물체의 운동 애니메이션과 함께
힘, 질량, 가속도 값을 표시한다.


--------------------
2. 운동량 보존
--------------------

두 카트가 충돌한다.

사용자가:
- 카트 질량
- 초기속도
- 충돌 방식

을 조절한다.

충돌 전/후 운동량을 비교한다.

p = mv

운동량 보존 여부를 수치로 보여준다.


--------------------
3. 에너지 보존
--------------------

롤러코스터 또는 공의 낙하 실험.

높이를 조절하면
위치에너지와 운동에너지가 변화한다.

전체 역학적 에너지가 보존되는 것을 그래프로 표시한다.

PE + KE = constant


--------------------
4. 중력
--------------------

두 천체를 화면에 표시한다.

사용자가:
- 질량
- 거리

를 조절한다.

중력의 크기가 변화한다.

F = Gm₁m₂/r²

거리와 힘의 관계를 그래프로 보여준다.


--------------------
5. 단순 조화 운동
--------------------

스프링에 매달린 질량.

사용자가:
- 질량
- 스프링 상수
- 초기 변위

를 조절한다.

실시간 진동을 보여준다.

위치-시간 그래프를 제공한다.


--------------------
6. 파동과 중첩
--------------------

두 개의 파동을 표시한다.

사용자가:
- 진폭
- 파장
- 주파수
- 위상

을 조절한다.

두 파동의 합성 결과를 실시간으로 보여준다.


--------------------
7. 간섭
--------------------

두 광원 또는 파동 발생기를 표시한다.

사용자가:
- 파장
- 위상
- 광원 간 거리

를 조절한다.

보강간섭과 상쇄간섭을 시각화한다.

간섭무늬를 실시간으로 생성한다.


--------------------
8. 회절
--------------------

레이저와 슬릿을 표시한다.

사용자가:
- 슬릿 폭
- 파장

을 조절한다.

스크린에 나타나는 회절무늬가 변화한다.


--------------------
9. 굴절
--------------------

공기 → 물 → 유리 등의 매질을 선택한다.

입사각을 조절한다.

빛의 진행방향이 변한다.

스넬의 법칙을 함께 보여준다.

n₁sinθ₁ = n₂sinθ₂


--------------------
10. 전자기 유도
--------------------

자석과 코일을 표시한다.

사용자가 자석을 직접 움직인다.

코일의 감은 횟수와 자기장 세기를 조절한다.

유도기전력과 전류 변화를 그래프로 보여준다.


--------------------
11. 원자 구조
--------------------

원자 모형을 표시한다.

양성자/중성자/전자 수를 조절한다.

원소와 동위원소가 어떻게 달라지는지 보여준다.


--------------------
12. 전자배치
--------------------

전자껍질 또는 오비탈에 전자를 배치한다.

원자번호를 선택하면 전자배치를 보여준다.

전자배치와 원소의 성질 사이의 관계를 설명한다.


--------------------
13. 주기율
--------------------

인터랙티브 주기율표.

원소를 선택하면:
- 원자번호
- 원자량
- 전자배치
- 원자반지름
- 전기음성도
등을 보여준다.

주기율표를 이동하면서 성질의 경향을 시각화한다.


--------------------
14. 이온결합
--------------------

Na와 Cl 같은 원자를 표시한다.

전자의 이동을 직접 보여준다.

Na⁺와 Cl⁻가 형성되고
정전기적 인력으로 배열되는 모습을 보여준다.


--------------------
15. 공유결합
--------------------

원자를 드래그해서 분자를 만든다.

H₂
O₂
H₂O
CO₂

등을 만들 수 있도록 한다.

전자쌍 공유를 시각화한다.


--------------------
16. 분자 구조와 VSEPR
--------------------

중심 원자와 결합 수를 선택한다.

선택 결과에 따라
선형,
굽은형,
삼각 평면,
삼각뿔,
정사면체
등의 구조를 3D 또는 준3D로 보여준다.

결합각도 표시한다.


--------------------
17. 분자 극성
--------------------

분자를 회전시켜 볼 수 있게 한다.

원자별 전기음성도 차이를 표시한다.

분자의 쌍극자 방향을 화살표로 표시한다.

분자의 구조에 따라 전체 극성이 달라지는 것을 보여준다.


--------------------
18. 화학량론
--------------------

반응식을 선택한다.

예:
2H₂ + O₂ → 2H₂O

사용자가 H₂와 O₂의 양을 조절한다.

어떤 물질이 제한 반응물인지 자동으로 판단하고
생성물의 최대량을 계산한다.


--------------------
19. 반응속도
--------------------

화학반응을 입자 수준에서 애니메이션으로 보여준다.

사용자가:
- 온도
- 농도
- 표면적
- 촉매

를 조절한다.

반응속도 변화와 충돌 빈도를 시각화한다.


--------------------
20. 산·염기와 pH
--------------------

용액을 선택하거나 혼합한다.

H⁺ 농도와 OH⁻ 농도,
pH,
색상 변화를 함께 보여준다.

pH = -log[H⁺]

로그가 실제로 어떤 의미인지 시각적으로 설명한다.


--------------------
21. 세포막과 확산
--------------------

세포막 양쪽에 입자를 배치한다.

농도 차이를 조절한다.

입자가 고농도 → 저농도로 이동하는 것을 애니메이션으로 보여준다.


--------------------
22. 삼투
--------------------

반투과성 막을 사이에 둔다.

물과 용질의 이동을 시각화한다.

양쪽 용액 농도를 조절한다.

세포가 팽창하거나 수축하는 현상을 보여준다.


--------------------
23. 효소 작용
--------------------

효소와 기질을 3D 또는 2D 형태로 보여준다.

온도와 pH를 조절한다.

최적 조건에서 반응속도가 가장 높은 것을 그래프로 보여준다.


--------------------
24. ATP와 세포호흡
--------------------

포도당 → 해당과정 → Krebs cycle → 전자전달계

전체 과정을 단순화된 시각화로 보여준다.

ATP 생성량을 단계별로 표시한다.


--------------------
25. DNA 복제
--------------------

DNA 이중나선을 표시한다.

DNA를 열고
상보적 염기쌍이 결합하는 과정을 애니메이션으로 보여준다.

A-T
G-C

규칙을 직접 확인할 수 있게 한다.


--------------------
26. 전사와 번역
--------------------

DNA → mRNA → 단백질

과정을 단계별로 체험한다.

사용자가 DNA 염기서열을 선택하면
mRNA가 만들어지고
codon에 따라 아미노산이 연결된다.


--------------------
27. 멘델 유전
--------------------

부모의 유전자형을 선택한다.

Punnett square가 자동으로 생성된다.

자손의 유전자형과 표현형 확률을 보여준다.


--------------------
28. 자연선택
--------------------

서로 다른 특성을 가진 개체군을 만든다.

환경을 바꾼다.

세대가 반복되면서 특정 형질의 비율이 변화하는 모습을 시뮬레이션한다.


--------------------
29. 판구조론
--------------------

지각판을 직접 드래그한다.

발산형,
수렴형,
보존형
경계를 만들어본다.

판 이동에 따라:
- 지진
- 화산
- 산맥
등이 발생하는 것을 보여준다.


--------------------
30. 지진파
--------------------

P파와 S파를 발생시킨다.

사용자가 지층을 설정한다.

파동이 지층을 통과하면서 어떻게 달라지는지 보여준다.

P파와 S파의 속도 차이도 표시한다.


--------------------
31. 화산
--------------------

마그마 저장소를 시각화한다.

압력,
마그마 점도,
가스량
등을 조절한다.

분출 형태의 차이를 보여준다.


--------------------
32. 물순환
--------------------

바다, 대기, 구름, 지표를 연결한다.

온도와 태양에너지를 조절한다.

증발 → 응결 → 강수 → 유출
과정을 애니메이션으로 보여준다.


--------------------
33. 온실효과
--------------------

지구와 대기를 단순화해서 표현한다.

CO₂, CH₄ 등의 농도를 조절한다.

태양복사와 지구복사 에너지 흐름을 표시한다.

단, 실제 과학을 왜곡하지 않도록
온실효과와 지구온난화를 구분해서 설명한다.


--------------------
34. 결정구조
--------------------

원자들을 3D 격자 형태로 보여준다.

FCC
BCC
HCP

구조를 선택한다.

회전/확대/축소할 수 있게 한다.

단위격자와 원자 배치를 표시한다.


--------------------
35. 결정 결함
--------------------

완벽한 결정구조를 보여준다.

사용자가:
- 공공
- 치환형 불순물
- 간극형 불순물
- 전위

를 삽입할 수 있도록 한다.

결함이 재료 특성에 어떤 영향을 주는지 설명한다.


--------------------
36. 응력과 변형률
--------------------

막대 시편을 잡아당긴다.

사용자가 힘을 조절한다.

응력-변형률 그래프를 실시간으로 생성한다.

탄성변형과 소성변형,
항복점,
파괴를 시각화한다.


--------------------
37. 브래그 법칙과 XRD
--------------------

X선 발생기와 결정 구조를 표시한다.

사용자가 입사각 θ를 조절한다.

브래그 법칙:

nλ = 2d sinθ

에 따라 특정 각도에서 회절 조건이 만족되는 것을 보여준다.

회절 패턴을 그래프로 생성한다.

d-spacing과 결정구조의 관계를 설명한다.


--------------------
38. Raman 분광법
--------------------

Raman 실험실을 구현한다.

구성:

[Laser]
↓
[Sample]
↓
[Scattered Light]
↓
[Detector]
↓
[Raman Spectrum]

사용자가:
- 레이저 파장
- 레이저 세기
- 시료 종류
- 측정 범위

를 조절할 수 있게 한다.

Raman spectrum의 피크가 어떻게 나타나는지 보여준다.

Rayleigh scattering과 Raman scattering을 구분해서 설명한다.

Stokes / anti-Stokes 개념도 학부 초급 수준에서 설명한다.

중요:

"라만분광법 = 빛을 쏘면 물질의 분자 진동 정보를 얻을 수 있다"

라는 핵심 개념을 가장 먼저 이해할 수 있게 한다.


--------------------
39. SEM
--------------------

가상의 SEM 장비 인터페이스를 만든다.

사용자가:
- 가속전압
- 배율
- 전자빔 조건
- 검출기

등을 조절할 수 있게 한다.

시료 표면 이미지가 변화하도록 한다.

SEM의 기본적인 원리를 설명한다.

광학현미경과 SEM의 차이도 비교한다.


--------------------
40. PN 접합
--------------------

P형 반도체와 N형 반도체를 연결한다.

전자와 정공을 표시한다.

공핍층이 형성되는 과정을 애니메이션으로 보여준다.

사용자가 순방향/역방향 전압을 조절한다.

전류 변화를 그래프로 보여준다.


==================================================
6. 과학적 정확성
==================================================

중요하다.

이 앱은 과학 교육용이므로
그럴듯해 보이는 가짜 과학을 만들지 않는다.

각 이론의 설명과 시뮬레이션은
학부 초급 수준의 표준적인 과학 개념에 기반해야 한다.

다만 비전공자용 앱이므로 처음부터 수식과 전문용어를 쏟아내지 않는다.

설명 순서:

현상
↓
직관
↓
핵심 개념
↓
과학적 원리
↓
수식
↓
실제 적용

7. 난이도 시스템

🟢 BASIC

"학부 수준"

🔴 DEEP DIVE
"조금 더 깊게"

UNIVERSITY:

단, DEEP DIVE는 MVP에서는 간단한 placeholder로 만들어도 된다.

처럼 설명한다.


==================================================
9. 인터랙션 설계 원칙
==================================================

모든 실험에서 다음 원칙을 지킨다.

1. 조작하면 즉시 결과가 변해야 한다.
2. 슬라이더에는 현재 수치를 표시한다.
3. 가능하면 애니메이션과 그래프를 동시에 사용한다.
4. 결과가 왜 변했는지 설명한다.
5. 사용자가 직접 예측해볼 수 있는 요소를 넣는다.

예:

"질량을 2배로 늘리면 가속도는 어떻게 될까요?"

[예측하기]

그 후 실험 결과를 보여준다.

17. 개발 우선순위
==================================================

한 번에 40개를 대충 구현하지 말고
다음 순서로 개발한다.

PHASE 1

먼저 앱의 전체 구조와 디자인 시스템을 완성한다.

그리고 대표 실험 5개를 고품질로 만든다.

1. 뉴턴의 운동법칙
2. 간섭
3. 산·염기와 pH
4. DNA 복제
5. Raman 분광법

이 5개는 서로 다른 형태의 인터랙션을 보여주는
대표적인 데모가 되어야 한다.

PHASE 2

나머지 35개 이론을 동일한 디자인 시스템에 맞춰 추가한다.

PHASE 3

검색,
학습 진행률,
관련 이론,
난이도,
분야 간 연결을 완성한다.


==================================================
18. 최종 목표
==================================================

사용자가 앱을 처음 실행했을 때

"나는 문과라서 과학을 잘 모르는데..."

라는 상태에서 시작해,

Raman을 직접 조작하고,
XRD 회절패턴을 만들어보고,
DNA를 복제해보고,
PN 접합에서 전자의 움직임을 보고,
중력과 파동을 직접 조작하면서

"아, 그래서 이런 현상이 발생하는 거구나."

라고 느끼게 만드는 것이 목표다.

즉,

SCIENCE LAB은
"과학을 설명하는 앱"이 아니라
"과학을 직접 실험해보는 앱"

이어야 한다.

먼저 현재 프로젝트 구조를 확인하고,
위 요구사항에 맞는 전체 정보 구조와 컴포넌트 구조를 설계한 뒤 구현을 시작하라.

기존 코드가 있다면 기존 기능을 함부로 삭제하지 말고
재사용 가능한 구조로 확장하라.

최종적으로 실제 브라우저에서 바로 실행 가능한 수준의 MVP를 만들어라.
